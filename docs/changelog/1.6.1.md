# 吐槽弹幕网客户端 v1.6.1

Date: 2026-11-01

## Highlights

- 播放页简介下方新增 `系列` 区域, 列出站点给这部作品整理的各季投稿, 排在相关视频前面, 可以直接跳到其他季.

## Features

- 系列: 取自站点播放页的视频列表, 不额外请求; 按季数排列, 剧场版与特别篇跟在后面, 卡片左上角标出季数, 当前视频标出 `正在播放`.
- 系列: 只有站点整理过系列的作品才显示, 除当前视频外没有其他条目时不占位置; 已屏蔽的视频不显示.
- 系列: 站点视频列表里早年的单集链接都指向第一季, 点开对不上标题, 这类条目不列出.
- 相关视频: 系列里已经列出的投稿不再重复出现.
