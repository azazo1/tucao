# 吐槽弹幕网客户端 v1.3.0

Date: 2026-10-18

新增横屏与平板适配, 启动检查更新, 以及可调整的主站域名, 并补充参考项目与官网入口.

## Highlights

- 宽屏设备改用左侧导航栏, 首页, 时间表与番组索引按可用宽度排布列数.
- 播放页在横屏与平板改为左侧播放器加右侧简介与评论, 手机竖屏保持上下结构.
- 启动时查询 GitHub Release, 有新版本时提示并打开下载页, 可选择稍后或忽略该版本.
- 设置页可修改主站域名, 站点换域名时不必等新版应用.

## Features

- 适配: 主框架在宽度 600 以上改用左侧导航栏, 旋转时保留各页滚动与分页状态;
  首页推荐流, 时间表与番组索引的网格按可用宽度计算列数, 横屏不再固定两列.
- 播放页: 横屏与平板改为左侧播放器加右侧简介与评论; 退出全屏后不再强制竖屏.
- 宽屏: 设置, 私信, 评论, 搜索, 档案, 视频列表与登录表单在宽屏下限宽居中.
- 更新提示: 启动时查询最新正式发布并与当前构建版本比较, 对话框展示发布说明;
  确认后用系统浏览器打开发布页, 附官网下载页并说明该页非本人管理, 链接可能撤去或更新延迟;
  稍后下次启动再提示, 忽略后不再提示该版本, 关于对话框可手动检查. 应用不申请安装权限.
- 站点域名: 设置页其他分组新增站点域名, 支持恢复默认; 保存后重启应用生效,
  换域名后可能需要重新登录.
- 关于: 新增 PiliPlus 与吐槽官网链接, 保留原有参考项目.

## Fixes

- 修正退出全屏后应用无法横屏的问题.

## Upgrade Notes

1. 包版本为 1.3.0, Android 构建号为 4. 建议覆盖安装, 不要先卸载,
   卸载会删除应用本地历史, 收藏和外部专属缓存.
2. 新增两项偏好: 站点域名与跳过的版本, 旧版本升级后直接使用默认值.
3. 修改站点域名后需要重启应用; cookie 按域名保存, 换域名后可能需要重新登录.
4. 更新提示只跳转系统浏览器, 应用内不下载也不安装.
5. 发布提供 arm64-v8a, armeabi-v7a 与 x86_64 三种 APK 和 SHA256SUMS.
   多数安卓手机请选择 tucao-1.3.0-android-arm64-v8a.apk.
6. 验证范围为静态检查, 单元与控件测试及 CI 三种架构的 APK 构建, 未进行真机验收.
