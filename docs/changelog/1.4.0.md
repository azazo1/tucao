# 吐槽弹幕网客户端 v1.4.0

Date: 2026-10-19

本版本是一次大更新. 安卓端新增局域网投屏, 消息中心, 图评与续命等一批功能,
更新提示也从跳转浏览器改成应用内下载安装包; 同时带来一个 Go 写的命令行客户端,
它随本版本一起发布六个平台的归档.

## CC 娘素材声明

- 本版本广告页新增的 CC 娘感谢素材 (探头与鞠躬动画的图集及静态图) 由 AI 生成,
  只在看完广告后表达感谢, 不代表站点官方形象.
- 该素材不用于商业用途, 也不随应用收费; 若版权方认为不妥, 会随时删除或替换.

## 命令行客户端

新增 `tucao` 命令行工具, 与安卓端共用同一套接口解析, 覆盖 Linux, macOS 与
Windows 的 x86_64 和 aarch64 六个平台.

- 功能涵盖首页概览与在线人数, 分区, 八类榜单, 热搜与 u 榜, 搜索, 番组索引与
  本周新番, 档案列表与详情, 用户空间, 私信, 视频详情与统计, 评论, 弹幕导出与发送,
  单文件下载, 账号与本地收藏.
- 输出统一为 `ok` / `schema_version` / `data` 结构, 交互终端出表格, 管道里出 YAML;
  退出码区分用法错误, 未登录与 safety 拒绝, 写操作不重试.
- `safety` 提供 read_only, non_destructive 与 confirm_dangerous_actions 三个开关.
- 配置放 `~/.config/tucao/`, 站点域名可改, 收藏与历史放 `~/.local/share/tucao`.
- `image user` 下载用户头像与横幅, 图片按内容校验真实格式, 站点占位图与坏文件
  不再落盘; 下载改用播放页里的完整分P地址, 断流后按已有分片自动续传.

## 局域网投屏

播放页右上角新增投屏入口, 搜索同一网段里支持 DLNA 的电视.

- 投屏期间播放器区域换成电视遥控: 显示电视名与传输状态, 进度条可拖动, 提供
  后退前进 5 秒, 播放暂停与退出; 跳转在松手时才下发, 进度条不会先弹回旧位置.
- 手机侧起一个很小的转发服务补上站点直链需要的 Referer 与 UA, 透传 Range,
  电视不会因为防盗链拉不到流; 弹幕不参与投屏, 设备弹层里有说明.
- 投屏前释放本地播放, 退出后按电视停下的位置续播; 电视端被遥控器停下会自动收尾,
  切换分P会收起投屏.
- 仓库内新增 mock 电视脚本供联调, 使用方式见 `docs/mock-tv.md`.

## 应用内更新

- 更新提示按设备 ABI 从 release 产物里挑出对应的安装包, 对话框显示包名与体积,
  没有匹配产物时按钮退回发布页.
- 安装包在应用内前台下载, 同时只跑一个任务, 回到后台即中断并丢弃半成品;
  关于对话框就地显示进度, 可取消, 重试与安装.
- 经 FileProvider 发起安装意图, 先查安装未知应用的放行状态再引导去系统设置.
- 关于页检查更新不再退出对话框, 检查期间两个入口置灰, 防连点重复请求.

## 消息中心

- 私信页接入站点的系统公告, 列表按未读标记, 详情把正文拆成段落与图片两种块,
  段落里的链接点开系统浏览器, 图片可全屏查看.
- 消息页新增评论列表, 数据取自会员中心的评论页, 解析封面, 分区, 标题, 作者, 日期
  与正文, 条目可跳回档案或视频, 支持下拉刷新与分页.
- 修复打开私信就掉登录: 站点把会话与 UA 绑在一起校验, 消息请求此前用桌面 UA,
  站点判成未登录并让 cookie 失效; 现在统一用与登录一致的手机 UA, 页面没有消息
  容器且出现登录字样时提示登录状态已过期.
- 「我的」页的私信与评论入口以及底部入口显示未读数量, 取数只请求会员中心页,
  不替用户清掉评论未读; 换号或退出登录时归零, 取数失败保留上一次的数字.

## 评论区

- 评论正文还原 HTML 实体, 十六进制与十进制数字实体, 没进表的命名实体以及二次
  转义的 `&amp;#39;` 都能解出来, 与简介共用同一套解码.
- 评论里的站内图片按原始宽高比内联显示缩略图, 点击进全屏查看; 站外图片不自动
  联网, 用户点过才取图, 站外的表情地址也不再当表情加载.
- 破会员可在顶层评论里发送图评, 图片单张限 2MB.
- 发送按钮固定 32 高, 与紧凑图标按钮底边对齐.

## 我的与账号

- 我的页顶部卡片铺上自己的横幅, 头像压在下沿并带描边, 点卡片进入自己的用户空间;
  修改密码与退出登录集中到自己的主页, 只在查看自己时显示.
- 用户空间页的头像与横幅可以放大查看并保存到相册; 用户主页头部显示用户编号.
- 我的页下拉刷新登录状态, 头像横幅与续命卡片一并重新取数, 失败时保留本地缓存.
- 修复登录请求缺少 `dosubmit` 时站点直接返回登录页, 导致误报用户名或密码错误.

## 图片查看

- 图片查看改用 `extended_image`: 双击放大到点击位置, 再双击还原, 双指缩放与
  放大后拖动由库负责.
- 双击缩放改用自己驱动的补间动画, 260ms easeOutCubic, 放大时保持手指所在的点
  不动, 动画途中按下即停.
- 长按弹出保存到相册与取消的菜单, 不再长按即存; 保存走原生 MediaStore,
  Android 10 起不需要存储权限.
- 修正查看页按图片原始尺寸贴在左上角, 居中与缩放失效的问题.

## 破会员与续命

- 登录后按站点 `vip` 字段识别破会员, 我的页与用户空间页的昵称渲染成金色流光并
  飘几颗小粒子, 我的页昵称后附一枚同款小标签; 评论区的一级评论仍按站点的会员色
  标出破会员的 uid.
- 续命卡片显示 cc娘还能存活的天数, 本人累计续命天数, 进度条与贡献者头像, 附会员组,
  积分与账号年限, 点按进入新增的贡献榜页面.
- 会员中心与贡献榜只能抓页面, 先按手机 UA 请求, 取不到续命区块再换桌面 UA;
  登录态失效或站点改版时显示诊断卡写明原因.

## 广告与 CC 娘

- 应用内点开广告时补上站点的点击上报, 与站点脚本一样在渲染时已登录才上报,
  同一个广告位每轮只报一次, 上报失败不挡住广告页打开.
- 破会员打开广告入口不再请求广告位, 改为一句对白, CC 娘鞠躬比心动画与一行免广告
  状态, 点击角色可重播.
- 看完最后一个广告返回列表后显示 CC 娘扶边探头感谢动画, 广告列表为空时改为静态
  感谢页; 系统开启减弱动画时只显示静态图.
- 收尾页的人物贴住底边并加底部渐隐, 气泡尾巴转向人物.

## 播放页

- 简介上方新增番组摘要, 点按从底部弹层查看类型, 别名, 首播, 原作, 导演与角色配音
  等全部字段; 弹层左侧展示番组封面, 封面点按可放大查看.
- 全屏控制条新增选集入口, 只在全屏且分P多于一个时出现; 底部弹层列出全部分P,
  当前项高亮, 没有直链的第三方源画删除线.
- 三个点菜单新增重启播放器, 走控制器重新拉详情并重开当前分P, 保持重启前的进度与
  播放状态; 右上角的重启按钮重进当前路由, 播放器, 弹幕与详情一并重新拉取.
- 修复选集按钮在非全屏时报 GetX 错误: 全屏判断原本写在 Obx 回调里并与分P条件
  短路相连, 回调读不到可观察量.

## 追番与收藏

- 站点追番接入播放页统计条与我的收藏页: 统计条上的追番项点一下加入, 再点取消;
  我的收藏页改成 本地收藏 / 追番 两个页签, 追番条目可跳播放页并支持取消与下拉刷新.
- 站点没有可用的追番状态接口, 是否已追番与取消都读会员中心的追番夹页面.
- 退出登录或换号时丢掉追番缓存.
- 修复追番提交中统计条抖动: 不再把可点外壳的 onTap 置空, 提交中用同尺寸转圈
  顶替图标, 高度保持不变.

## 界面

- 卡片底色与描边拉开层次, 暗色下卡片与页面背景不再糊成一片.
- 新增横幅组件: 解码后量一次平均亮度, 近乎全黑的图不铺上去, 空地址与加载失败
  同样只画主题容器色渐变.
- 我的页头部卡片压低尺寸, 减少被提示条压住的条目.

## 工程与发布

- 命令行工具接入 CI 与发布: 一个 runner 交叉编译六个平台并校验文件头架构与二进制
  里的版本号, 测试在 Linux, Windows 与 macOS 上各跑一遍, 归档与 apk 进入同一个
  release, 共用一份 SHA256SUMS.
- 预发布 release 的滚动 tag 不再移动, 只在首次创建时落位, 之后更新标题, 说明与
  产物, 本地 `git fetch` 不再报 would clobber existing tag.
- Actions 升级到带 Node 24 的版本, 消除 Node 20 弃用告警.
- just 命令按产品分子模块重整, 统一为 `just <产品> <动作>`.

## 升级说明

1. 包版本为 1.4.0, Android 构建号为 5. 建议覆盖安装, 不要先卸载,
   卸载会删除应用本地历史, 收藏和外部专属缓存.
2. 没有新增偏好项, 站点域名, 弹幕参数等旧设置直接沿用.
3. 更新提示改为应用内下载安装包, 首次安装需允许本应用安装未知应用;
   下载在前台进行, 回到后台会中断, 发布页与官网下载页仍可从对话框打开.
4. 投屏要求电视与手机在同一网段并支持 DLNA, 手机侧会临时起一个很小的转发服务;
   弹幕不参与投屏.
5. 发布提供 arm64-v8a, armeabi-v7a 与 x86_64 三种 APK, 六个平台的命令行归档
   以及 SHA256SUMS, 共 10 个文件. 多数安卓手机请选择
   tucao-1.4.0-android-arm64-v8a.apk, 命令行工具按平台选择 tucao-cli-*.
6. 验证范围为静态检查, 单元与控件测试及 CI 的三架构 APK 与六平台 CLI 构建,
   未进行真机验收.
