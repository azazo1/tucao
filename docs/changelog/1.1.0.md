# 吐槽弹幕网客户端 v1.1.0

Date: 2026-10-12

新增本地收藏, 离线缓存与账号管理, 改进视频页布局和弹幕设置.

## Highlights

- 播放器下方提供简介 / 评论两个 tab, 点击或左右滑动切换, 不再打开二级评论页.
- 播放中可调整弹幕文字样式, 透明度, 时长, 显示区域与字幕避让.
- 调整进度时将手指移入顶部左右角可取消, 移回正常区域可继续; 全屏返回按钮与控制条共同显隐.
- 新增本地收藏, 直链单文件离线缓存, 私信收件箱及会话页面.
- 新增注册, 修改密码与邮箱找回密码页面.

## Features

- 弹幕: 支持字号, 字重, 系统字体选项, 透明度, 描边, 行高, 滚动时长,
  固定弹幕时长, 显示区域, 字幕避让, 类型开关及允许重叠. 设置页与播放页复用同一面板,
  保存失败恢复原设置, 预览不会恢复暂停的播放.
- 评论: 首次切到评论时加载, 切换 tab 或分P保留列表与滚动状态,
  各视频实例独立持有评论控制器, 保留楼中楼, 点赞与发送入口.
- 收藏: 视频页提供收藏与取消入口, 我的页面可管理本地收藏; 不需要登录, 不与站点账号同步.
- 缓存: 视频页可多选直链分P, 支持前台队列, 暂停, 从头重试, 删除与本地播放.
  视频与任务清单使用 Android/data 的应用外部专属目录, 外部存储不可用时提示重试,
  不回退到内部 /data/data 存放视频.
- 私信: 新增收件箱和会话详情, 支持发送与回复, 未登录时提示登录.
- 账号: 内置注册表单, 修改密码与邮箱找回密码, 按站点响应显示结果.
- 视频链接: 支持复制当前分P链接和浏览器备用入口.

## Fixes

- 修复站点 total_count 语义导致第一页后无法继续分页的问题.
- 修正评论楼层编号, 请求字段和回复参数, 各分P共用同一视频的评论楼层.
- 隔离迟到的详情与弹幕响应, 串行加载播放器, 防止快速切分P后打开旧视频或记录错误历史.
- 播放失败显示错误与浏览器备用入口; 后台迟到加载遵守后台播放偏好.
- 修复取消下载后立即重试与迟到进度的竞态, 清单写入成功后才发布缓存完成状态.
- 缓存主清单损坏时尝试备用恢复, 写盘或删除失败时保留可管理记录.
- 账号表单对空响应和未知响应不再显示假成功, 登录态变化时拒绝旧请求回写.
- 补充窄屏, 大字, 异步保存与路由覆盖的交互回归测试.

## Upgrade Notes

1. 包版本为 1.1.0, Android 构建号为 2. 建议覆盖安装, 不要先卸载;
   卸载会删除应用本地历史, 收藏和外部专属缓存.
2. 原有九项弹幕偏好自动迁移为版本化样式记录, 其他播放器设置不变.
3. 缓存位于 Android/data/com.azazo1.tucao/files/downloads/.
   Android 11 及以上通常限制文件管理器访问这个目录.
4. 当前仅支持直链单文件缓存, 不支持 HLS 分段缓存或后台下载.
   暂停及失败后从头重试, 重启应用不会自动恢复下载流量.
5. 发布提供 arm64-v8a, armeabi-v7a 与 x86_64 三种 APK 和 SHA256SUMS.
   多数安卓手机请选择 tucao-1.1.0-android-arm64-v8a.apk.
6. 验证范围为静态检查, 离线单元与控件测试及 CI APK 构建, 未进行真机验收.
