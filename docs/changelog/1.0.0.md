# 吐槽弹幕网客户端 v1.0.0

Date: 2026-10-12

首个版本. 基于 Flutter 重建吐槽弹幕网安卓客户端, 接口沿用官方最新安卓端的定义.

## Highlights

- 首页按新番 / 影剧 / 综合分区浏览, 支持子分区切换与分页加载.
- 视频播放支持多分P, 倍速, 全屏与进度记忆, 弹幕样式可配置.
- 评论支持楼中楼, 点赞与发送, 登录态通过 cookie 持久化.
- 排行榜与新番索引按页面解析实现, 覆盖官方已废弃的 json 接口.

## Features

- 首页: 三分区信息流, 网格卡片, 下拉刷新与触底加载.
- 分区列表: 按最新 / 弹幕 / 播放排序.
- 排行榜: 全站与各分区, 今天 / 本周 / 本月 / 今年四个时间维度.
- 搜索: 关键词搜索, 分区过滤, 排序, 本地搜索历史.
- 新番索引: 按年月浏览番组.
- 播放器: 多分P切换, 倍速, 全屏, 播放进度本地记录与续播.
- 弹幕: 滚动 / 顶部 / 底部弹幕渲染, 透明度 / 字号 / 显示区域 / 速度 / 描边可调, 支持发送.
- 评论: 评论列表, 楼中楼展开, 点赞, 发送评论.
- 播放历史: 本地记录, 支持删除单条与清空.
- 登录: 站点账号登录, cookie 持久化, 支持退出登录.
- 设置: 主题模式, 动态取色, 主题色, 播放器与弹幕参数.

## Upgrade Notes

1. 本版本为首次发布, 直接安装 `tucao-1.0.0-android-arm64-v8a.apk` 即可.
2. 应用需要网络权限访问站点接口与视频源.
3. 站点账号密码不会被本地保存, 登录态仅保留 cookie.
