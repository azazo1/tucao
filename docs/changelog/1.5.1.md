# 吐槽弹幕网客户端 v1.5.1

Date: 2026-11-01

## Highlights

- 更新包新增国内镜像下载源, 设置里可切自动, 国内镜像或官方源, 镜像清单可自行增删与测速, 下载改为分段并发, 弱网下明显更快.
- 时间表卡片标出番剧每周的更新时刻, 当天已到点的标出可以观看, 并支持按时刻排序.
- 设置页新增 `首页` 分组, 提供 `显示公告顶幅`, `显示继续观看卡片` 与 `显示广告入口` 三个设置项.
- 手机横屏矮屏下主标签竖到左侧, 站务通知与继续观看并成顶上一条横幅.

## Features

- 更新与下载: 设置里可选下载源与并发连接数, 新增镜像源页面管理加速站并逐个测速, 服务器不支持分段时自动退回单连接.
- 首页与时间表: 时间表显示更新时刻并按时刻排序, 当天所属分组加圆点, 卡片重排时平滑移动; 横屏矮屏下标签改为竖排.
- 页面菜单: 档案详情, 档案列表与用户空间右上角新增三点菜单, 可复制链接或在浏览器中打开.

## Bug Fixes

- 首页公告顶幅一进来停在第二篇, 现在从第一篇开始.
- 时间表下拉刷新会重置选中的星期.
- 时间表卡片的更新时刻与封面上的弹幕数角标位置重合.
- 测速超时改为给出已读部分的速度; 镜像源页面在手机上左右贴边.
- 下载开始的提示条不再带取消按钮.
