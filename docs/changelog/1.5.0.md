# 吐槽弹幕网客户端 v1.5.0

Date: 2026-11-01

本版本集中打磨播放体验, 并补上本地屏蔽, 长按复制与站务公告等日常功能.

## Highlights

- 播放器新增自动连播, 续播提示, 全屏锁屏, 左侧竖滑调亮度和 2.5x / 3x 倍速, 长按倍速可在设置页选择.
- 弹幕支持屏蔽词与重复合并, 进度条上方新增弹幕高能条, 全屏时可一键跳到下一个高能点.
- 番剧与视频可以在本地屏蔽, 屏蔽后首页, 搜索, 排行, 收藏与历史都不再显示.
- 首页新增站务公告卡片和可左右滑动的继续观看卡片, 时间表里已追的番会标出并排在前面.
- 档案与系统公告正文还原站点的富文本样式, 评论, 私信和标题支持长按复制.

## Features

### 播放器

- 分P播完后显示 5 秒倒计时并自动播放下一P, 没有直链的失效源会跳过; 设置页可关闭自动连播.
- 按历史续播时, 画面左下角提示从哪里继续, 并提供 `从头播放`; 切换分P时也接着该分P上次的进度播放.
- 全屏时顶栏显示标题, 当前分P和时间, 可以直接发弹幕; 左侧的锁按钮可锁定画面, 防止误触.
- 左半侧竖滑调节本应用的画面亮度, 右半侧竖滑调节音量, 离开播放页后亮度交还系统.
- 新增 2.5x 与 3x 倍速档位; 长按倍速可在设置页选择 2x, 3x 或 4x, 默认 3x.
- 设置页新增 `双击两侧快退快进`, 开启后双击画面左右两侧可后退或前进 10 秒, 默认关闭.
- 视频首帧出来前用模糊封面垫底; 点卡片进入播放页时, 封面会从列表飞进播放器.
- 控制条显隐带淡入淡出, 竖屏播放时也会自动隐藏.
- 双击快退快进, 长按倍速, 锁屏和拖动取消时有触感反馈, 跟随系统的触感设置.

### 弹幕

- 弹幕设置面板新增屏蔽页, 屏蔽词不区分大小写, 用 `/` 包起来时按正则匹配.
- 10 秒内内容相同的弹幕合并为一条, 达到 3 条时标注条数, 默认开启.
- 进度条上方显示弹幕密度高能条, 默认开启, 可在设置页的弹幕分组关闭; 全屏控制条可一键跳到下一个高能片段.
- 发送弹幕时可选滚动, 顶部, 底部和 10 种颜色; 自己发的弹幕带边框显示, 发送成功不再弹提示条.

### 首页与浏览

- 首页主标签栏上方显示站务公告卡片, 带封面, 自动轮换也可左右滑动, 关闭后本次运行内不再显示.
- 时间表顶部显示最近 7 天没看完的视频, 最多 5 条, 可左右滑动切换, 卡片标出看到的分P与进度.
- 登录后时间表里已追的番标出 `已追`, 并排在当天分组的前面.
- 首页分区与番组索引首次加载显示骨架屏.
- 重复点击底部导航回到顶部, 已在顶部时下拉刷新当前列表; 切换底部入口时新页面淡入.
- 启动图标换成新绘制的吐槽电视, 支持 Android 13 单色主题图标.

### 屏蔽与历史

- 列表长按, 播放历史菜单和播放页菜单可屏蔽番剧与视频, 记录只保存在本机; 设置页新增屏蔽管理, 可逐条或全部解除.
- 播放历史的分P列表给看完的集打勾, 看了一部分的集画出进度, 并自动滚到当前集.
- 删除, 清空播放记录和屏蔽后, 提示条上提供 `撤销`, 停留 4 秒.

### 复制与正文

- 评论, 楼中楼, 我的评论和私信长按可复制全部或自由选择文字; 系统通知, 档案正文与视频简介可以选择文字.
- 播放页标题, 档案标题, 用户空间昵称与用户 id 长按直接复制.
- 视频卡片与排行条目长按菜单统一为查看标题图, 复制标题, 复制视频链接与屏蔽; 标题图可全屏查看并保存到相册.
- 档案与系统公告正文保留站点的加粗, 斜体, 颜色, 字号, 对齐与链接, 同一段落里的相邻图片并排显示; 站内视频, 档案和用户空间链接在应用内打开.

### 界面

- 应用内提示统一为底部浮动提示条, 新提示直接替换旧提示, 不再挡住顶部标题栏.

## Bug Fixes

- 播放器: 按历史续播, 重启播放器或结束投屏回到本地播放时, 有时没有回到原进度, 而是从头播放.
- 播放器: 视频缓冲转圈时弹幕仍在滚动.
- 播放页: 简介的展开 / 收起按钮只能点在文字上, 现在整行都可点击.
