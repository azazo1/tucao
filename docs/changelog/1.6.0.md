# 吐槽弹幕网客户端 v1.6.0

Date: 2026-11-01

## Highlights

- 播放页简介下方新增同系列相关视频, 按季序排好, 可在设置里关闭.
- 离线缓存重做: 支持断点续传, 多任务同时下载与分段连接, 一并保存封面, 弹幕和视频信息, 离线播放与在线共用同一个播放器, 还可以投屏.
- 搜索栏粘贴站内链接可直接打开对应的视频, 档案或用户空间.
- 档案正文里的表格按行列显示, 不再拆成竖排文字.

## Features

- 相关视频: 根据标题里的作品名和别名搜索同系列投稿, 按正篇季序, 总集篇, 剧场版, OVA, 外传排列, 卡片左上角标出季数; 设置页播放器分组新增 `显示相关视频`, 默认开启.
- 离线缓存: 点整行暂停或继续, 长按删除, 暂停, 断网或连接中断后从断点续传; 缓存页分为正在缓存与已缓存两块, 已缓存按视频分组显示封面, 分P数与大小, 可整体删除或更新.
- 离线缓存: 设置页新增 `离线缓存` 分组, 可调 `同时缓存数` (默认 2) 与 `单任务连接数`; 选择缓存分P时可一键全选.
- 离线缓存: 离线播放带弹幕, 未缓存的分P可以转到在线观看; 离线页顶栏可投屏, 由手机把本地文件传给电视.
- 搜索: 粘贴 `play/h`, `play/d`, `play/u` 链接直接进入视频, 档案与投稿人主页, 视频链接里的 `#n` 会跳到对应分P; 站点换了域名的链接也能识别.
- 正文: 表格按站点的列宽排开, 列多时可横向滚动, 深色模式下表格底色跟随主题; 支持分隔线和图片高度.
- 图片查看: 长按菜单可复制图片链接.
- 用户空间: 不存在或已注销的用户显示明确提示; uid 0 (游客弹幕聚合账号) 显示说明, 不再显示成空页面或自己的空间.

## Bug Fixes

- 播放页: 从首页时间表, 收藏, 排行等列表进入时总是从第一P开始, 现在接着上次看的那一P播放.
- 播放: 部分视频地址里带 `&` 时无法播放, 报 Failed to recognize file format.
- 播放器: 全屏时从屏幕边缘下滑呼出系统栏会同时调节亮度或音量.
- 播放器: 打开新的播放页后, 之前页面的视频仍在后台播放.
- 排行: 追番榜的追番数被显示成播放量, 无人区榜的 `xx%人错过` 文案被截成数字.
- 时间表: 加载更新时刻期间卡片反复来回跳动, 现在到齐后只重排一次, 并显示加载进度条.
