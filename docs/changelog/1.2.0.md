# 吐槽弹幕网客户端 v1.2.0

Date: 2026-10-18

新增画中画播放, 播放统计, 热搜推荐与首页广告入口, 补全档案详情与评论区, 并修正一批播放与解析问题.

## '广告' 声明

- 本版本的广告入口是希望以实际访问表达对官网的支持, 感谢站长长期维护吐槽弹幕网.
- 广告内容与链接取自官网首页广告位, 该接入方式能否真正为站点带来收益暂时未知,
  客户端无法确认结算归属.
- 广告只表现为首页标题栏上的一个入口按钮, 不弹出, 不遮蔽内容, 不影响浏览, 播放, 搜索等任何正常使用;
  设置页可关闭该入口, 关闭后首页不再显示.
- 如果广告的接入方式存在问题, 请及时交流, 客户端会相应调整或移除该入口.

## Highlights

- 播放器支持画中画: 控制条可主动进入系统小窗, 设置页开启自动画中画后回桌面即继续播放, 小窗只保留画面.
- 播放页标题下新增播放 / 在线 / 评论 / 弹幕 / 追番统计条, 在线人数每 30 秒刷新, 切前后台时暂停并补拉.
- 首页标题栏显示站点总在线人数, 顶层新增档案标签, 档案详情补齐统计与评论区.
- 搜索页在历史记录下方展示两列热搜推荐, 热搜榜改为按今天 / 本周 / 本月 / 今年分组.
- 评论支持站点表情, 楼中楼改为可展开的独立区块, 子回复支持分页与失败重试.

## Features

- 播放器: 底部按钮重排为左侧播放暂停, 后退 5 秒, 前进 5 秒与跳转按钮, 右侧弹幕开关, 弹幕设置, 倍速与全屏;
  跳转按钮按设置秒数前进, 用来跳过片头片尾.
- 播放器手势: 横向拖动改为固定 90 秒跨度, 视频不足 90 秒时按整段换算; 拖动中进度条游标实时跟随,
  手指移到顶部左右角取消, 移回正常区域继续.
- 画中画: 设备支持时控制条出现画中画按钮, 按当前画面比例进入小窗; Android 12 及以上交给系统的
  setAutoEnterEnabled, 更低版本在离开界面时自行判断, 设置页新增开关.
- 统计: 解析 ol.php 与 api.php?op=count 返回的统计脚本, 取出在线人数, 总播放量与追番数;
  评论数复用评论接口的 total, 只取一条评论.
- 首页: 标题右侧用灰色小字显示站点总在线人数与播放器数, 标签为 在线 / 观看, 与官方客户端一致;
  其中一个数值缺失时只显示有数据的一项.
- 广告: 从站点首页 header_rmb 广告位解析全部广告图与链接, 首页按钮进入应用内广告列表,
  点某一条用 WebView 打开; 需要系统应用处理的协议交给外部, 页面右上角保留浏览器打开入口.
- 广告入口: 按钮改为无背景的炫彩图标, 只保留兑换券图标并做缓慢色相循环, 周围漂浮贴近图标的粒子;
  列表页与 WebView 页底部说明广告收益情况.
- 广告开关: 设置页其他分组新增显示广告入口, 广告页与列表页可取消广告, 二次确认后关闭入口并返回主页.
- 搜索: 热搜推荐点按直接搜索, 前三名序号用主色与暖色强调, 标题行右侧的更多进入完整热搜榜.
- 搜索: 未搜索时整页支持下拉刷新热搜; 没有搜索历史时提示改用更浅的文字色, 并拉开与标题的间距.
- 搜索: 结果页返回先清空关键词回到搜索页, 再按一次才退出; 从热搜榜点入的搜索仍返回上一页.
- 榜单: 热搜页顶部增加时间分组选择条, 切换后只显示该组, 不再把各组合并成从 30 之后又从 1 开始的列表.
- 评论: 评论正文解析为文字与表情段, 表情用内联图片渲染, 普通图片显示为 [图片] 占位;
  评论输入弹层新增表情面板, 点按插入站点表情代码.
- 评论: 楼中楼展开入口移入正文列, 展开后使用独立圆角区块, 子回复支持分页, 失败重试,
  发送成功后重拉所在楼第一页并更新回复数; 评论头像与昵称可进入用户空间, 匿名评论保持不可点击.
- 档案: 首页新增档案标签, 列表支持嵌入式布局; 详情新增正文与评论两个 tab, 评论首次切到时才请求;
  正文优先取 .show_content, 避免抓到页头, 并解析分类与发布时间显示在标题下方.
- 视频简介: 还原 HTML 实体与换行, 播放页在后台补拉完整正文, 三行量出确实被截断时才显示展开与收起;
  播放统计移到简介下方, 紧挨分 P 上方的分隔线.

## Fixes

- 修复部分 Adreno 设备上打开界面即崩溃: 主题的水波纹效果改用标准 InkRipple, 不再触发驱动编译着色器的崩溃路径.
- 修复硬件解码器回退到软件解码时被误判为播放失败: 这类信息只记 warning, 不再盖住正常画面.
- 修复热搜关键词以数字开头时排名解析错误, 例如 1月 被解析成排名 61.
- 修复热搜数据返回后推荐区不刷新: 搜索页改为在构建时先取一次热搜快照.
- 修复竖版卡片在抓取结果不含作者时整片显示未知: 作者行改为只在取到作者名时显示.
- 修复档案分类里重复的档案项: 档案自身就是未筛选列表, 不再作为分类请求.
- 修复动态取色与自定义主题色同时生效的问题: 开启动态取色时主题色圆点置灰并禁止点击,
  并清空自定义色, 旧版本遗留的并存状态以动态取色为准.
- 修复楼中楼展开后回复不显示, 下拉刷新后列表不重建, 以及档案详情正文容器取错的问题.
- CI: 固定镜像预装的 NDK 版本, 复用 Gradle 构建缓存, 修正 NDK 覆盖的注册时机.

## Upgrade Notes

1. 包版本为 1.2.0, Android 构建号为 3. 建议覆盖安装, 不要先卸载;
   卸载会删除应用本地历史, 收藏和外部专属缓存.
2. 新增三项偏好: 自动画中画, 跳转按钮秒数, 显示广告入口, 默认分别为开启, 90 秒和显示,
   旧版本升级后直接使用默认值.
3. 开启动态取色时不再允许选择主题色, 升级后如果两者同时存在, 进入设置页会清空自定义主题色.
4. 画中画需要 Android 8.0 及以上且设备声明支持该特性, 不支持的设备不显示按钮与开关.
5. 发布提供 arm64-v8a, armeabi-v7a 与 x86_64 三种 APK 和 SHA256SUMS.
   多数安卓手机请选择 tucao-1.2.0-android-arm64-v8a.apk.
6. 验证范围为静态检查, 单元与控件测试及 CI 三种架构的 APK 构建, 未进行真机验收.
