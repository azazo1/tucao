# CC 娘 Q 版生图提示词

根据输入的 CC 娘官方设定参考图, 重新设计一张适用于手机弹幕视频应用的 Q 版吉祥物角色设定图. 这是 Q 版化重设计, 绝对不要照搬参考图的正常人体比例.

画布要求: 横向 1536x1024, 真正透明的 alpha 背景, 不是棋盘格背景. 三个等宽区域, 左边是正面全身, 中间是四分之三侧面全身, 右边是背面全身. 每个区域中只画同一角色的一种视角, 彼此完全分离不重叠. 每个角色含头发和衣服的完整轮廓必须完全位于自己的区域内, 上下左右留出至少 8% 空白. 三个人物相同高度, 头顶和脚底对齐. 没有标题, 没有标注, 没有文字, 没有色卡, 没有边框, 没有背景装饰, 没有地面或投影. 只交付干净可拆分的三视图角色素材.

Q 版造型: 2.4 头身, 大而圆润的头, 小巧短四肢, 软萌但精神活泼, 可爱友善的应用看板娘. 正面表情是温暖微笑, 双眼睁开, 身体略有动态但整体正面, 双手自然放在身体两侧稍微张开, 五指可简化成干净的卡通小手, 脚朝前. 不画成人比例, 不性感化, 不画夸张胸部.

角色辨识度: 保留参考图的樱粉色超长头发, 小呆毛, 粉红眼睛, 额前斜分刘海, 发束在下方形成饱满的 C 形弯曲, 发尾有白色圆盘配黑色播放三角的发饰. 头发长度和弧线要为 Q 版重构, 不拖到脚下, 不让头发像多余肢体. 服装保留白色露肩连衣裙和黑色领口滚边, 黑色细颈带与小结, 黑腰带, 白色小电视笑脸腰扣, 黑色裙摆局部装饰, 白手套, 白长靴与黑靴口. 保留简洁黑白粉配色, 不增加其他颜色和复杂装备. 三个视角中服饰结构, 头发长度, 配件所在身体侧一致.

视觉风格: 精致现代日系 Q 版 2D 游戏 UI 吉祥物, 清楚稳定的深棕黑色描线, 线条圆润, 外轮廓稍粗, 内部细节简化, 柔和赛璐璐分层阴影, 少量柔和高光, 色彩清透. 缩小到手机界面的 96px 时仍能辨认. 白色衣服边界必须有清晰描线, 在深色和浅色应用背景上都可读. 非 3D, 非写实, 非像素画, 非素描. 不复制参考图背景或水印. 三个视角必须像同一位画师绘制的同一个 Q 版角色.
